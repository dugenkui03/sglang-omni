### punctuation

/ˌpʌŋktʃuˈeɪʃən/

- [n] Punctuation means marks that make writing easier to understand.
  - Example: Please add punctuation to this sentence.

### nested

/ˈnestɪd/

- [adj] Placed inside something else of the same kind.
  - Example: A nested list is a list inside another list.

### discrete

/dɪˈskriːt/

- [adj] Having separate possible values rather than a continuous range.
  - Example: OmniVoice learns to recover masked discrete audio tokens.
  - In this paper: "discrete diffusion" works with audio token IDs.

### backbone

/ˈbækbəʊn/

- [n] The main neural network that processes the input and builds useful features.
  - Example: The backbone produces hidden states for the prediction heads.
  - In this paper: the "bidirectional Transformer backbone" processes text and audio information.

### bottleneck

/ˈbɒtlnek/

- [n] A limit that prevents enough information from reaching the next stage.
  - Example: Lost details can create an information bottleneck.
  - In this paper: an "information bottleneck" can reduce the detail or quality of generated audio.

### propagation

/ˌprɒpəˈɡeɪʃən/

- [n] The passing of something from one stage to another.
  - Example: A two-stage pipeline can suffer from error propagation.
  - In this paper: "error propagation" means that errors in an earlier stage affect a later stage.

### streamlined

/ˈstriːmlaɪnd/

- [adj] Made simpler and more efficient by removing unnecessary steps or parts.
  - Example: OmniVoice uses a streamlined end-to-end architecture.
  - In this paper: the architecture maps text directly to acoustic tokens in a single stage.

### comprises

/kəmˈpraɪzɪz/

- [v] Contains or consists of; the third-person singular form of "comprise".
  - Example: The model input comprises text tokens and acoustic tokens.
  - In an architecture description: introduces the parts that make up a whole.

### partitioned

/pɑːˈtɪʃənd/

- [v, past participle] Divided into separate parts.
  - Example: The acoustic sequence is partitioned into two segments.
  - In this paper: the acoustic token matrix is divided along the time axis into a prompt segment and a target segment.

### temporal

/ˈtempərəl/

- [adj] Related to time.
  - Example: Audio tokens are arranged along the temporal dimension.
  - In this paper: the temporal dimension represents the time steps of the audio sequence.
